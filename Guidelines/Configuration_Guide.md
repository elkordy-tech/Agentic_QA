# Configuration Guide

## AI Environment

Configure your preferred AI development environment (e.g., VS Code with GitHub Copilot, Claude Code, or OpenCode) to:

- Access the project files.
- Discover and use the available Agent definitions.
- Access the relevant Skills when executing tasks.
- Support task delegation between Agents when required.

## MCP Integrations

Configure the required MCP integrations based on the intended testing activities. for example:

| Integration    | Purpose                        |
| -------------- | ------------------------------ |
| Playwright MCP | Web application testing.       |
| Mobile MCP     | Mobile application testing.    |
| Jira MCP       | Defect reporting and tracking. |

Only configure the integrations required for your tasks.

## Verification

Ensure that:

- The AI environment can access the Agents and Skills.
- Required MCP integrations are connected.
- Each integration can perform its intended operations.
