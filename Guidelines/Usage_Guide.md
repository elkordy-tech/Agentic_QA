# Usage Guide

## Getting Started

Start by describing the QA task you want to perform to the QA Orchestrator.

## Requesting a Task

Include the following information when relevant:

- **Objective:** What do you want to achieve?
- **Scope:** Which application, module, or feature?
- **Inputs:** Available requirements, test scenarios, or related files.

## Task Execution

The QA Orchestrator will:

1. Understand your request.
2. Discover the available Agents.
3. Select and delegate tasks to the relevant Agents.
4. Coordinate execution and verify the results.
5. Report outputs and any blockers.

## Important Notes

- You can request individual QA activities without following a mandatory sequence.
- Provide review or approval checkpoints when needed.
- Only the requested tasks will be performed.
- Results depend on the available Agents, Skills, and tool integrations.
