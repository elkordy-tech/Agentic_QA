# Setup Guide

## Prerequisites

- Git.
- An AI development environment that supports custom Agents and project instructions (e.g., VS Code with GitHub Copilot, Claude Code, or OpenCode).
- MCP support for workflows that require external tools.

## Setup

**1. Clone the repository**

```bash
git clone https://github.com/elkordy-tech/Agentic_QA.git
cd Agentic_QA
```

**2. Open the project**

Open the repository in your preferred AI development environment.

**3. Configure the environment**

Configure the AI environment and required MCP integrations according to the [Configuration Guide](Configuration_Guide.md).

## Verification

Ensure that:

- The AI environment can access the project files.
- The framework's Agents and Skills are available.
- Required MCP integrations are working.
