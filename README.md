# QA Agentic Framework

An AI-powered, reusable framework that uses specialized agents and skills to support software testing activities.

## Key Features

- **Agent Orchestration:** Delegates QA tasks to specialized agents.
- **Exploratory Testing:** Explores applications and identifies test scenarios.
- **Test Design:** Generates structured test scenarios.
- **Test Execution:** Executes scenarios and records results.
- **Bug Reporting:** Reports confirmed defects with supporting evidence.

## Architecture

The framework follows a modular, agent-based architecture designed to support flexible task delegation and reusable testing workflows.

See [Architecture Documentation](Architecture.md) for the high-level architecture diagram and component overview.


## Project Structure

- `Agents/` – Specialized AI agent definitions.
- `Skills/` – Reusable testing workflows and instructions.
- `Guidelines/` – Setup and usage guidance.
- `Reports/` – Generated testing reports.
- `Architecture.md` – Framework architecture and component overview.
